Wear the **strategist hat** (`docs/PRINCIPLES.md § Role hats`). Validate this business idea: $ARGUMENTS

- Five blocks, each ≤3 lines: **Problem** (who hurts, when) / **Alternatives** (top 3 + their gap) / **Wedge** (why this wins — "nicer UI" doesn't count) / **Monetization** (who pays; reachable without ad spend?) / **Verdict: GO | PIVOT | KILL** + one line why.
- Bias: most ideas should die here, cheaply. KILL is a success, not a failure.
- On GO: draft `docs/PRD.md § Vision` (2–3 sentences) + `§ Pillars` (max 3, each with a metric), then hand off to `/spec` per feature.
- If a deep competitor/market sweep is needed (heavy web reads), offer to spawn the `idea-validator` agent instead of grinding it inline.
- Output: the five blocks (+ PRD draft on GO). No preamble.

## How to review

1. Read the table below; edit the **French** column (or send
   a list of `key -> new French`).
2. Apply each change to `lib/l10n/app_fr.arb` (same key).
3. Run `fvm flutter gen-l10n`, then `fvm flutter test`: the
   `*_fr_test.dart` files assert the exact French text, so a
   changed string needs the matching test expectation updated.
4. Re-run `fvm dart run tool/l10n_review.dart` to refresh this
   file.

Conventions to keep: informal "tu"; short and warm like the
English; brand "Convyve"; typographic apostrophe ’ (never the
ASCII one); keep `{placeholders}` as they are. ⍽ marks a
non-breaking space (U+00A0, before `: ! ? ;`, inside « », and
between a number and min/h/j/s/km): keep it as a real NBSP in
the ARB. Strings are short because the meal action bar and
buttons are fixed width: check any longer rewording at 320 px.
